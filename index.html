Connect your repository

PDFs and annotations stay in your private GitHub repository. Highlights are saved on this device right away and then sync on their own.

How to create the token
  1. Apri GitHub → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → pick only the repository with the PDFs.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Choose an expiration, generate the token and paste it here.

The token stays only in this device’s browser and can read and write only that repository.
