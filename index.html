Collega il tuo repository

I PDF e le annotazioni restano nel tuo repository GitHub privato. Le evidenziazioni si salvano subito su questo dispositivo e poi si sincronizzano da sole.

Come si crea il token
  1. Apri GitHub → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → scegli solo il repository dei PDF.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Scegli la scadenza, genera il token e incollalo qui.

Il token resta solo nel browser di questo dispositivo e può leggere e scrivere soltanto quel repository.
